# BMW-Sales-Analysis-Dashboard

🔍 Project Overview

This project presents a comprehensive BMW Sales Analysis Dashboard built to analyze sales performance, pricing trends, and regional distribution using a dataset of 50,000+ records (2010–2023).

The goal of this project is to derive meaningful business insights and visualize key metrics to support data-driven decision-making.

🛠️ Tools & Technologies Used

Microsoft Excel – Data preparation & initial analysis
SQL Server – Data cleaning, transformation, and querying
Power BI – Data modeling, visualization, and dashboard creation

📁 Dataset Information
Records: 50,000+
Time Period: 2010 – 2023
Fields include:
Model
Region
Price
Fuel Type
Transmission
Sales Data

📊 Key KPIs

Total Revenue: 19.01T
Gross Sales Value: 4Bn USD
Average Price: 75.03K
Max Price: 120K
Min Price: 30K
Total Models: 11

📈 Key Insights

7 Series is the top-performing model in terms of revenue
Sales trends remained relatively stable from 2010 to 2023 with peaks in recent years
Revenue contribution is evenly distributed across major global regions
Demand is balanced across Diesel, Petrol, Hybrid, and Electric fuel types

📌 Features of the Dashboard

Interactive filters:
Year
Model
Region
Fuel Type
Transmission
Visualizations include:
Sales trend over time
Revenue by region
Price analysis by model
Top-performing models
Fuel type distribution
